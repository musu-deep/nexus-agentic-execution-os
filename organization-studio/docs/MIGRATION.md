# Generalization Notes

This version was deliberately rebuilt rather than performing a mechanical text replacement.

## Removed from the legacy pattern

- organization-specific brand names,
- organization-specific logos,
- non-English interface labels,
- RTL-first layout assumptions,
- country-specific branch views,
- company-specific logistics labels,
- legacy localStorage prefixes,
- organization-specific executive titles,
- theme names tied to a specific entity.

## Generalized equivalents

| Legacy concept | NEXUS Organization Studio |
| --- | --- |
| CEO office dashboard | Organization Command Center |
| entity-specific business units | Projects and Portfolios |
| specific branch pages | Configurable organization units |
| AI advisor | NEXUS Missions |
| directives | Decision Center + Tasks |
| executive reports | Reports and Insights |
| compliance pages | Governance and Compliance |
| executive documents | Document Center |
| named company identity | Organization Settings |

## Why rebuild instead of rename

A direct rename would leave hidden assumptions in permissions, labels, demo data, theme names, storage keys, and information architecture. The new version treats organization identity as configuration and NEXUS as the autonomous execution layer.
